# 🚀 Production-Grade DevOps & Platform Engineering Extension

This repository extends Google's Online Boutique microservices demo into a production-oriented Kubernetes, DevOps, GitOps, Observability, and Platform Engineering learning environment.

The goal of this repository is to demonstrate how modern cloud-native platforms are designed, automated, secured, deployed, monitored, and operated using enterprise-grade DevOps tooling and production-style infrastructure practices.

## 🛠️ Platform Stack

| Category | Technologies |
|---|---|
| Cloud Platform | GCP, GKE |
| Infrastructure as Code | Terraform |
| GitOps | Argo CD |
| CI/CD | GitHub Actions |
| Kubernetes Packaging | Helm, Kustomize |
| Containerization | Docker |
| Registry | Artifact Registry |
| Observability | Prometheus, Grafana |
| Logging | Elasticsearch, Kibana, ECK Stack |
| Distributed Tracing | Tempo, OpenTelemetry |
| Security | Workload Identity, RBAC, NetworkPolicies |
| Secrets Management | External Secrets Operator, Google Secret Manager |
| Networking | Private GKE Cluster, Cloud NAT, VPC-native networking |
| Communication | gRPC |
| Automation | Bash scripting |
